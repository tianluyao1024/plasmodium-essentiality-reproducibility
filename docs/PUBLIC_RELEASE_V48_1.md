# Public release v48.1

This repository is the public, deployment-oriented reproducibility release for
the ProtoEss Atlas study. It contains only material approved for public reuse:

- processed labelled inputs for the three species-specific deployment models;
- class-separated CDS FASTA records;
- frozen deployment-model artefacts and their feature manifests; and
- scripts and instructions for model reuse.

It does not distribute the manuscript, genome-scale atlas calls, target
prioritisation records, docking results, figure source tables or unpublished
analysis workbooks. The public website serves the frozen v48.1 atlas as a
read-only research resource. Its CDS-first predictor uses a distinct
unknown-species-safe deployment family and is not the five-branch formal OOF
stack that generated the manuscript analyses.

The full formal-analysis code, fixed split manifests and processed inputs are
available to editors and reviewers during peer review and will be added to the
public Zenodo archive upon publication.
