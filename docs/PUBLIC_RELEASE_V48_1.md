# Public release v1.0.3

This public reproducibility release extends the prior three-malaria-species deployment resource to four source-labelled apicomplexan species by adding *Toxoplasma gondii* GT1 processed labels, class-separated CDS records and a practical deployment model. It also exposes the full formal five-branch analysis source tree, while retaining manuscript-specific fixed input bundles as reviewer-accessible materials during peer review.

The release intentionally excludes the manuscript, full genome-scale atlas, target-prioritisation records, docking outputs and unpublished result tables.
