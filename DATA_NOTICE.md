# Data notice

This repository redistributes only the processed labelled feature matrices and
class-separated CDS sequences used for the three species-specific deployment
models. The underlying genome sequences and annotations originate from public
VEuPathDB/PlasmoDB releases and the labelled essentiality data originate from
published genetic-screen resources. Use of these materials remains subject to
the licences, attribution requirements and terms of the original providers.

No manuscript, genome-wide prediction atlas, target-ranking output, docking
output, figure or unpublished result table is distributed in this repository.
